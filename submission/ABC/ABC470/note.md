# Inc,Dec,Xorについての考察

## 考えたこと
-   用意するもの:
    -   $A$の配列1個
    -   各値が何個含まれるのかを持つ配列$count$(初期値は$count_0$にNが入れる)
    -   現在のビット単位XORを表す$result$

-   用意したものに関して、全クエリを$O(logN)$までで更新したい

-   $Q==1$のパターン
    -   シンプルに$A_i$に1足して$result$を更新すれば良いので、$O(1)$ですべて更新できる

-   $Q==2$のパターン
    -   offsetを用意して、今の一番左端がどこかを持てば$A$と$count$は更新可能
        -   常にoffset番目のAは値0として取り扱う
    -   $result$をどうやって更新する..?


## 考察の材料になりそうなもの
-   前提:xor演算は2回同じ値で計算すると元に戻る
    ```
    2^3^3 => 2
    ```
    -   ということで、個数が奇数個の値に関しての総ビットxorを計算する
